# 1. CORPS PURS ET MELANGES
! *ESPECE CHIMIQUE* : Ensemble d'*ENTITES IDENTIQUES* (atomes, molecules, ions). Caracterisee par formule, aspect et proprietes physiques/chimiques.
! *CORPS PUR* : *1 SEULE* espece chimique.
! *CORPS PUR SIMPLE* : *1 SEUL TYPE* d'atome (ex: *Ag*, *C*, *O2*).
! *CORPS PUR COMPOSE* : *PLUSIEURS TYPES* d'atomes (ex: *H2O*, *C2H6O*, *NaCl*).
! *MELANGE* : *PLUSIEURS* especes chimiques.
! *HOMOGENE* : *1 SEULE PHASE* visible a l'oeil nu (ex: acier, the, air). Liquides *MISCIBLES* (ex: eau + ethanol).
! *HETEROGENE* : *PLUSIEURS PHASES* visibles a l'oeil nu (ex: eau + fer). Liquides *NON MISCIBLES* (ex: eau + huile).

# 2. COMPOSITIONS MASSIQUE ET VOLUMIQUE
! *PROPORTION MASSIQUE* : *m(E) / m(totale)* (entre *0* et *1*).
! *POURCENTAGE MASSIQUE* : *[m(E) / m(totale)] x 100* (en *%*).
! *PROPORTION VOLUMIQUE* : *V(E) / V(totale)* (entre *0* et *1*).
! *POURCENTAGE VOLUMIQUE* : *[V(E) / V(totale)] x 100* (en *%*).
! *COMPOSITION DE L'AIR* (en volume) : *78% N2* (diazote), *21% O2* (dioxygene), *1%* autres gaz.

# 3. GRANDEURS PHYSIQUES
! *MASSE VOLUMIQUE* : *RHO = m / V* (depend de l'etat physique et de la temperature *T*).
! *UNITES* : *g.cm-3* (ou *g.mL-1*), *g.L-1*, *kg.m-3*. Conversion : *1 cm3 = 1 mL*.
! *VALEURS DE REFERENCE* (20 deg C) : *RHO(EAU LIQUIDE) = 1,00 g.cm-3* = *1,00 kg.L-1* = *1000 kg.m-3* | *RHO(AIR) = 1,3 g.L-1* | *RHO(GLACE) = 0,92 g.cm-3* (a 0 deg C).
! *DENSITE* (solide/liquide) : *d = RHO(echantillon) / RHO(eau)* (*SANS UNITE*, meme unite pour les deux *RHO*).
! *CHANGEMENT D'ETAT* : Temperature *CONSTANTE* (palier) uniquement pour un *CORPS PUR*.
! *FUSION* : Solide <-> Liquide a *T(FUSION)*.
! *EBULLITION* : Liquide <-> Gaz a *T(EBULLITION)* (concerne *TOUT* le liquide a *T FIXE* != *EVAPORATION* en surface a *TOUTE T*). Gaz -> Liquide = *CONDENSATION LIQUIDE*.
! *SOLUBILITE (s)* : *MASSE MAXIMALE* dissoute dans *1 L* de solvant : *s = m(max) / V* (en *g.L-1*). Depend de *T* et du solvant.
! *SOLUTION SATUREE* : Contient la *MASSE MAXIMALE* de solute (*m = s x V*).

# 4. IDENTIFICATION D'ESPECES CHIMIQUES
! *GRANDEURS PHYSIQUES* : Comparer *T(FUSION)*, *T(EBULLITION)*, *RHO*, *s* ou indice de refraction aux *TABLES DE REFERENCE*.
! *TESTS CHIMIQUES* :
! *EAU (H2O)* : *SULFATE DE CUIVRE ANHYDRE* (blanc -> *BLEU*).
! *DIHYDROGENE (H2)* : Flamme -> *DETONATION* ("aboiement" / *CRI DU CHIEN*).
! *DIOXYGENE (O2)* : *BUCHETTE INCANDESCENTE* -> *SE RALLUME* vivement.
! *DIOXYDE DE CARBONE (CO2)* : *EAU DE CHAUX* -> *SE TROUBLE* (precipite blanc).
! *CHROMATOGRAPHIE (CCM)* : Separation par difference d'*AFFINITE* entre *PHASE FIXE* (plaque silice/papier) et *PHASE MOBILE* (*ELUANT* qui monte par *CAPILLARITE*).
! *LECTURE CCM* : *1 TACHE* = corps pur | *PLUSIEURS TACHES* = melange | Meme *HAUTEUR* que le temoin = *MEME ESPECE*.
